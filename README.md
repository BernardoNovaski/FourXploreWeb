# FourXplore

> **Protótipo / site em desenvolvimento.** Esta é uma versão inicial do portal da FourXplore, ainda sujeita a mudanças de conteúdo, design e funcionalidades.

A **FourXplore** é uma agência de marketing de experiências, passeios e turismo local, com atuação em **Campo Largo/PR**. A proposta é divulgar lugares, eventos e opções de lazer acessível, conectando o público (moradores e turistas) a parceiros comerciais como restaurantes, bares e pontos turísticos.

## Sobre o projeto

Este repositório nasceu de uma iniciativa de **projeto integrador da faculdade**, na disciplina de Desenvolvimento Front End (Análise e Desenvolvimento de Sistemas, Universidade Positivo). O objetivo acadêmico foi reunir, em um único portal temático, os conteúdos estudados em aula: HTML semântico, CSS, CSS Grid e JavaScript com manipulação do DOM.

O tema do portal foi baseado no plano de negócio da FourXplore, e a ideia é que ele evolua para um site real da empresa.

## Funcionalidades

- **Layout com CSS Grid:** colunas iguais, proporções diferentes (`1fr 2fr 1fr`) e áreas nomeadas (`grid-template-areas`).
- **Banner, cards de passeios e galeria de imagens** de pontos turísticos de Campo Largo.
- **Carrossel de imagens** com 8 passeios, legenda dinâmica, indicador de página e navegação pelo teclado.
- **Sistema de abas** com 6 abas (sócios, empresa e parceiros).
- **FAQ em formato accordion** com 6 perguntas.
- **Janela modal reaproveitável**, com conteúdo preenchido dinamicamente pelo JavaScript.
- **Tabela de roteiro semanal** de passeios.
- **Formulário de contato** com validação de 10 campos e mensagens de erro e sucesso.
- **Modo claro/escuro** e **4 opções de cor** para o tema.
- **Layout responsivo** para telas menores.

## Tecnologias

- HTML5 (elementos semânticos)
- CSS3 (CSS Grid, variáveis CSS, media queries)
- JavaScript puro (vanilla), sem frameworks ou bibliotecas externas

## Como executar

Não é necessário instalar nada.

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/BernardoNovaski/NOME-DO-REPOSITORIO.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador.

> Mantenha a pasta `img/` junto dos arquivos, caso contrário as imagens não serão exibidas.
